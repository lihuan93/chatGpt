# 本地书架 LocalShelf 1.2

iPhone 原生 SwiftUI 本地文件与音频播放器。M4A / MP3 使用 AVPlayer，WMA 使用 VLCKit。无广告、无会员，文件导入手机后可以离线播放。

## 当前功能

- **真实文件夹层级**：首页只显示根目录的直属文件夹与文件，子目录逐层进入，支持空文件夹。不会平铺音乐下面的歌手文件夹。
- **新建与导入**：每层右上角 ＋ 可新建文件夹、导入整文件夹或多选文件，复制到当前目录。同名项目自动加编号，不覆盖原文件。
- **播放队列**：只播放当前目录直属 M4A / MP3 / WMA，按文件名自然排序，2 排在 10 前；不递归合并子目录。
- **播放控制**：0.75×～3×、每0.25一档，快退15秒、快进30秒、拖进度、后台和锁屏播放。
- **独立设置**：每个文件夹分别记住倍速及顺序播放/列表循环/单曲循环模式；未设置过的文件夹默认列表循环，已手动选择的模式不变。
- **断点续听**：每个音频目录分别记录章节、秒数、最后收听时间，首页可继续最近收听。每5秒及暂停、切章、进入后台时保存进度。
- **睡眠定时**：快捷15/30/45/60分钟、自定义1～1440分钟、当前文件播完停止。记住上次选择，可一键重新开始；显示倒计时，可取消。定时暂停优先于循环。
- **其他文件预览**：在所属文件夹中通过系统 Quick Look 预览 PDF、DOC/DOCX、XLS/XLSX、MP4 等，实际格式与编码支持取决于 iOS。预览不参与音频队列和有声书进度。

## 用原项目升级

本次「文件夹、循环、定时」增量更新只需一起替换 `Library.swift`、`Views.swift`、`AudioPlayer.swift`，不改原项目、签名、图标和Info.plist。继续使用已添加的 VLCKitSPM 3.6.0，连接iPhone按⌘R覆盖安装。

详细步骤与真机验收清单见 [文件夹循环定时更新.md](文件夹循环定时更新.md)。原文件没有移动，进度和独立倍速继续使用原相对路径；如果在「文件」App移动或改名，旧设置不会自动迁移到新路径。

## 首次打开完整工程与安装

1. Mac 安装 **Xcode 16或更新版本**，使用与你的macOS、手机iOS兼容的Xcode；iPhone需iOS16或更新版本。
2. 打开 `LocalShelf.xcodeproj`，Scheme选择 **LocalShelf**。等待Swift Package依赖下载解析完成。完整工程已配置 `https://github.com/tylerjonesio/vlckit-spm.git`，锁定 **3.6.0**。首次多平台依赖压缩包约780MB，手机实际安装体积不同。
3. Xcode → Settings → Accounts 登录免费Apple账号。
4. 蓝色项目 → TARGETS → LocalShelf → Signing & Capabilities，勾选Automatically manage signing，Team选Personal Team，Bundle Identifier设为唯一值。已有手机App的用户必须使用原Team及原Bundle ID。
5. USB连接并解锁iPhone，信任Mac。按提示在手机「设置 → 隐私与安全性 → 开发者模式」打开开发者模式，重启并确认。
6. 顶部选择真实iPhone，按 **⌘R**。如需信任证书，到手机「设置 → 通用 → VPN与设备管理」信任自己的开发者账号。

免费Personal Team签名通常有效7天。连接Mac，用原项目、原Team和原Bundle ID再按⌘R即可重新签名覆盖安装，Mac需联网。**不要先卸载App**，卸载会删除本地文件和进度。重要原始文件请在Mac保留备份。

## Finder传书与音乐

建议先按目录整理：

```
音乐/
  陈慧娴/
    01.mp3
    02.wma
  其他歌曲.m4a
凡人修仙传/
  第1章.m4a
  第2章.m4a
  第10章.m4a
```

连接iPhone → Finder侧栏选iPhone →「文件」→「本地书架」，拖入整个文件夹，可多选批量传。等复制结束后，App下拉刷新。点进目录选择音频播放，不会把子目录混入该目录的列表。

也可在App进入目标文件夹，点 ＋ 从「文件」选择导入。App执行复制，原文件保留；重复导入产生副本。云端来源需要先下载或联网读取，导入完无需联网。大批导入请保持App前台、确保空间足够；失败时已成功项目保留，重试仅选择失败项目。

在系统「文件」App把文件**移动到**「我的iPhone → 本地书架」则不会由App再额外复制。App内暂未实现移动、重命名和删除。

## 定时与循环细节

在播放页选择播放模式或点「定时」。快捷时间与自定义时间按真实经过的时间计时，不受倍速影响，手动暂停也不会冻结倒计时。切换目录时定时继续；「本文件播完后停止」跟随实际当前文件。

取消定时保留上次选择。重开App会显示上次选择但**不自动启动定时，也不恢复强制退出前的倒计时**。定时暂停音频，不强行关闭App。

列表循环最后一首回到本文件夹第一首；单曲循环当前文件。睡眠定时、手动暂停优先于自动切章；手动上一首/下一首可切换单曲循环中的曲目。

## 数据与兼容性

- 文件：App沙盒 `Documents/`，开启Finder共享和「文件」App访问。
- 进度：`Library/Application Support/listening-progress.json`，原子写入。
- 倍速和循环模式：UserDefaults内按Documents相对目录路径存储；上次定时选择单独存储。
- 覆盖安装改变沙盒绝对路径不影响相对路径匹配。移动、重命名会改变标识。
- WMA直接读取原文件，不转码、不生成第二份播放文件；DRM加密WMA不支持，其他变体的解码与定位精度需以实际文件验证。
- App突然被系统终止或强制结束时可能损失最近约5秒进度；先暂停可立即保存。强制结束会停止音频。
- 第三方依赖、版本和许可证见 `ThirdPartyNotices/`。
