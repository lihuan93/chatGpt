# 拾序 · 个人项目看板

无需安装依赖的静态网页。中文界面，支持项目新增、编辑、删除、三种状态、优先级、截止日期、标签、搜索、筛选以及 JSON 导入导出。首次打开有四个可编辑的示例项目。

## 本地运行

在此目录执行 `python3 -m http.server 8000 --directory dist`，然后访问 http://localhost:8000 。

数据保存在浏览器 localStorage，仅当前浏览器和网站地址可用，不会自动跨设备同步。通过导出和导入备份迁移数据。导入会追加项目，保留原有数据。

## 仓库组织

这个目录是独立的小项目。其他实验可以放在仓库的相邻目录；以后需要独立维护时再拆成新仓库。
