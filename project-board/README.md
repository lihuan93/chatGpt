# 拾序 · 个人项目看板

## 在线地址

[打开拾序个人项目看板](https://shixu-project-board-lh93.syrupy-crumb-2402.chatgpt.site)

当前为私有访问，仅所有者登录 ChatGPT 后可打开。

无需安装依赖的静态网页。中文界面，支持项目新增、编辑、删除、三种状态、优先级、截止日期、标签、搜索、筛选以及 JSON 导入导出。首次打开有四个可编辑的示例项目。

## 本地运行

在此目录执行 `python3 -m http.server 8000 --directory dist`，然后访问 http://localhost:8000 。

数据保存在浏览器 localStorage，仅当前浏览器和网站地址可用，不会自动跨设备同步。通过导出和导入备份迁移数据。导入会追加项目，保留原有数据。

## 仓库组织

这个目录是独立的小项目。其他实验可以放在仓库的相邻目录；以后需要独立维护时再拆成新仓库。

## 一键整理周报

点击“我的项目”旁的“一键整理周报”，默认整理当前周，也可以选周内任意一天。统计使用北京时间，周一至周日。

- 本周完成：仅计入完成日期在所选周内的已完成项目。
- 当前进行中、待开始：整理当前看板状态，待开始仅作为下周计划候选，不代表已承诺的计划或历史快照。
- 旧的已完成项目没有完成日期，会单独列出，不会猜测完成时间。编辑项目可补填日期。
- 切换到已完成会自动记录当天日期，重新打开项目会清除完成日期。
- 周报草稿可以编辑、复制或下载 Markdown；切换日期会重新生成草稿。不会调用外部 AI 服务或上传项目数据。
- 导出的 JSON 备份保留完成日期，旧备份仍可导入。

运行验证：`node --test tests/*.test.cjs`。
